# world

## 贪吃蛇游戏 (Snake Game)

一个经典的贪吃蛇游戏实现，使用HTML、CSS和JavaScript开发。

### 如何开始

1. 直接在浏览器中打开 `snake.html` 文件
2. 点击"开始游戏"按钮开始玩

### 游戏说明

- **控制方式**:
  - 使用方向键 (↑↓←→) 控制蛇的移动方向
  - 也可以使用 WASD 键控制
  - 在移动设备上可以通过滑动屏幕来控制方向
  - 按空格键暂停/继续游戏

- **游戏规则**:
  - 🍎 吃到红色的食物可以增长身体并获得10分
  - 🐍 蛇会随着吃到的食物越来越长
  - ⚠️ 不要撞到墙壁或自己的身体，否则游戏结束
  - 📈 吃到的食物越多，蛇移动的速度会逐渐加快
  - 🏆 最高分会自动保存在浏览器本地存储中

### 游戏特性

- 流畅的游戏体验
- 渐进式速度提升
- 最高分记录保存
- 响应式设计，支持移动设备
- 精美的视觉效果和动画
- 中文界面

### 技术栈

- HTML5 Canvas
- CSS3 (渐变、动画)
- JavaScript (ES6+)
- LocalStorage (用于保存最高分)
