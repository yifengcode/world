# 五子棋 Gomoku Game

一个简单而精美的网页版五子棋游戏，支持双人对战。

A simple and beautiful web-based Gomoku (Five in a Row) game with two-player support.

## 游戏特性 Features

- 🎮 15x15 标准棋盘 (Standard 15x15 board)
- ⚫⚪ 双人对战模式 (Two-player mode)
- 🎯 自动检测获胜条件 (Automatic win detection)
- 🔄 重新开始功能 (Reset functionality)
- 🎨 精美的界面设计 (Beautiful UI design)
- 📱 响应式布局 (Responsive layout)

## 如何游玩 How to Play

1. 打开 `index.html` 文件在浏览器中
2. 黑方先行，双方轮流在棋盘上落子
3. 率先在横、竖、斜任一方向形成连续五子者获胜
4. 点击"重新开始"按钮可以开始新游戏

1. Open `index.html` in your browser
2. Black player goes first, players take turns placing pieces
3. First to get 5 in a row (horizontal, vertical, or diagonal) wins
4. Click "重新开始" (Reset) button to start a new game

## 游戏规则 Game Rules

- 黑方(⚫)先手，白方(⚪)后手
- 双方轮流在棋盘的空白交叉点上放置棋子
- 率先在水平、垂直或对角线方向形成连续五个己方棋子的一方获胜
- 棋盘填满且无人获胜则为平局

## 技术栈 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
